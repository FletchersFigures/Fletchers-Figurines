# Fletcher's Figures Website

A responsive static website for Fletcher's Figures, using the orange, yellow and black colours from the supplied logo.

## Files

- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu, live order total and email order form
- `assets/logo.jpg` — supplied Fletcher's Figures logo

## Publish it so anyone can visit

This is a static website, so it can be hosted free on GitHub Pages.

1. Create/sign in to a GitHub account.
2. Create a new repository, for example `fletchers-figures`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will give you a public website address that you can share.

The order form opens the visitor's email app with the order details filled in. It does not require a database or server.
